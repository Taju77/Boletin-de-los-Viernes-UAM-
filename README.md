# Boletin-de-los-Viernes-UAM-

Serie de PDFs de los Boletines de los Viernes de la Delegada de Comunicación y Redes Sociales de la UAM (2023-2025)

Este repositorio tiene como objetivo ser de ayuda a los estudiantes de las Universidades Públicas de España (UAM, UC3M, URJC, UPM) para poder tener una idea más completa acerca de las oportunidades laborales en España y otras partes del mundo
